Para hacer uso de este programa, se requieren realizar los siguientes pasos:

1.Agregar a un cliente:
para realizar este paso, solo se requiere rellenar lo solicitado en la parte superior de la pantalla,
datos tales como nombre de cliente y correo electronico.
Después de rellenar esos dos datos, hacemos Click en el botón registrar cliente y como vemos automáticamente se guarda el cliente
en el sistema, observándosen los datos del cliente registrado

2. Crear y confirmar una reserva:

Para esto el usuario deberá de seleccionar el cliente ID el cual esta representado en orden de tiempo de registro correspondiéndole el ID 001,
luego de ello se realiza la seleccion del servicio el cual esa visualmente representado en la tabla de servicios disponibles.
se realiza la selección de la duración el cual corresponde también a los datos de la tabla, ejemplo: $25000 por hora, Duración 1-2-3 horas, a gusto del tiempo de servicio
se selecciona la modalidad de accesoria, participantes de la sala, ya que hay una capacidad permitida por sala que corresponden a 20 y equipos para alquilar el cual es
visible en la tabla de servicios y costos, luego de haber rellenado la información solicitada, se da a dar la selección del botón crear y confirmar reserva, y como se verá en pantalla
se evidencian algunos de los datos de las reservas confirmadas
Nota: las 3 tablas solo representan la informacion actual del sistema

3. procesamiento del servicio

en la cacilla de seleccion de reservas confirmadas, en el menú desplegable del lado derecho de crear y confirmar reserva, hacemos la selección de la reserva confirmada a procesar y hacemos click
en el botón procesar y mostrara información de la reserva.

4.boton simular las 11 operaciones
este botón simula las 11 operaciones solicitadas el cual muestra información detallada del sistema y los procesos realizados ejemplo:

1. Cliente válido registrado: Johan
2. Error de cliente inválido controlado
3. Servicio de sala registrado: Sala principal ($25000)
4. Error de servicio inválido controlado
5. Servicio de equipo registrado: Proyector ($40000)
6. Servicio de asesoría registrado: Asesoría especializada ($60000)
7. Reserva confirmada para Johan en Sala principal
8. Reserva procesada por $53550.00
9. Error de duración controlado
10. Falta de equipos controlada
11. Reserva confirmada y cancelada

Datos de referencia: Johan, Sala principal, Proyector y Asesoría especializada.
Origen del cliente de prueba: cliente registrado.
